# Название ПланФикса в коде и документации

Правила написания бренда для пользовательских сообщений, логов, комментариев, docstring, README и технической документации.

## Обычный текст

Во всех русскоязычных текстах использовать написание **ПланФикс**:

- без кавычек;
- с заглавной «Ф»;
- с обычным русским склонением: «в ПланФиксе», «с ПланФиксом», «для ПланФикса», «данные из ПланФикса».

При первом текстовом упоминании допускается вариант **ПланФи́кс** с ударением. В дальнейшем использовать «ПланФикс» без ударения.

Не использовать в обычном тексте варианты `PlanFix`, `Planfix`, `PlanFix API`, «План Фикс» или «официальный бот ПланФикса».

## Технические идентификаторы

Английское написание допустимо, когда это точное техническое имя, которое нельзя переводить или переименовывать:

- URL и домены: `https://example.planfix.ru`, `planfix.ru`;
- REST API: `POST /task/`, `GET /task/{id}`;
- переменные окружения: `PLANFIX_API_TOKEN`, `PLANFIX_ACCOUNT`;
- имена классов, модулей, функций и полей базы: `PlanfixClient`, `planfix_user_id`, `payback.planfix`;
- точные значения, которые возвращает или требует API.

Не изменять технические идентификаторы только ради соблюдения написания бренда: это может сломать интеграцию, конфигурацию или совместимость с API.

## Смешанный текст

Если в предложении есть и русское описание, и технический идентификатор, разделять их:

```python
# ✅ ПланФикс временно недоступен; задача будет повторно отправлена.
logger.warning("Planfix request failed: %s", error)

# ✅ Бот создаёт задачу в ПланФиксе через POST /task/.

# ❌ Planfix временно недоступен.
# ❌ Бот создаёт Planfix task.
```
